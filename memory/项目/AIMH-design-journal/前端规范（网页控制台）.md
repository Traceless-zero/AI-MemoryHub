# 前端规范（网页控制台）

> `目录结构树.html` 及相关前端工程约定的权威说明。FM 字段契约见 `SCHEMA.md`。

## 1. 零依赖单文件铁律与 vendored 资源

`网页控制台/目录结构树.html` 是 **vanilla HTML/JS 单文件**，`tree_server.py` 每次 GET **重读文件**吐出，**无构建步骤、无 node_modules**。

markdown 渲染用的 `网页控制台/marked.min.js` = **marked@4.3.0 UMD 的本地 vendored 副本**，随仓库走而非 CDN，目的是**保离线可用**。

⚠️ **前端严禁引入任何 CDN 或 npm 依赖**；要升级 marked 必须再 vendored 一份本地文件。

## 2. 引外部静态资源 = 后端必须同步提供（教训）

凡在 HTML 里加 `<script src="marked.min.js">` 这类**相对路径外部资源**，`tree_server.py` 的 `do_GET` **必须新增 `_send_static` 路由**去服务该文件：

- 仅限 HERE 目录内
- 阻断 `..` 目录穿越
- `.js` → `application/javascript`
- **MIME 映射的 key 必须带点**（因 `os.path.splitext` 返回的是 `.js` 而非 `js`）

否则链条是：该资源 404 → 库变量 `undefined` → 内联脚本顶部抛错 → **整段脚本中断，连不相关的 `loadTree()` 都不跑**。

2026-08-28 真实炸过一次，表现为**结构树无法加载**。写完必须 curl 验 `Content-Type` 的真实值。

## 3. marked 渲染约定：`breaks:true` 与 renderMarkdown 三项职责

marked 默认 `breaks:false` 会**吞掉硬换行**（单换行、段间不空行的段落），而用户 prose / 论文 / 随笔普遍这么写（程谦论文「摘要」就是连续 5 行无空行）→ **必须开启 `breaks:true`**。

`renderMarkdown` 保留三项自研职责：

1. 剥 front-matter `^---\n…\n---`
2. `marked.use({renderer})` 注入 heading 的 `id="secN"`（锚点目录 / `jumpToHeading` 依赖）；tablecell 注入 `style="text-align:…"` 绕过 CSS 的 `text-align:left`
3. paragraph 渲染器把 `breaks` 产生的 `<br>` **拆回独立 `<p>`**，还原旧 CSS `.reader p{margin:10px 0}` 的段间距

改渲染后须用 node 跑真实 .md 验证（代码块内 `|` 不误判为表格、表格对齐转 inline style、标题 id 连续）。

## 4. 设计语言与布局定调

- **浅灰纸面 + 赭金点缀（`#B0791E`）**，**坚决不绿**
- 避开 AI 三套路：奶油+衬线+陶土 / 黑底+霓虹绿 / 报纸排版
- 布局 = **小说阅读平台式**：顶部居中搜索 + 主内容浏览器 + 右侧伸缩结构树侧边栏，可重排结构
- 唯一硬约束：**不破 `/api/tree`、`/api/search`、`/api/md` 契约**；`API=''` 时走 mock 兜底

## 5. 工具选型：ui-ux-pro-max 优于 frontend-design

已装 `ui-ux-pro-max`（`~/.workbuddy/skills/ui-ux-pro-max/`，scripts + data 走 jsDelivr CDN 避开 800KB+ 大 json）：

```bash
python scripts/search.py "<query>" --design-system
```

输出具体配色 / 字体 / 组件规格（design tokens 带 hex）。

**经验**：纯审美类强化用 `frontend-design` 易偏个人风格；要**可落地强化**优先 `ui-ux-pro-max`。网页控制台正是用它从「靛紫个人极简」重做为「绿底 OLED 运维控制台 + Fira Code/Sans 等宽技术字体」。

## 6. stop-that-shit：机器强制版愿景与当前不装的理由

AIMH 的「Agent 自检注意事项」是**软约束**（技能指令层，靠 AI 自律）。社区有更硬的机器强制原型 **`stop-that-shit`**（lennney, MIT）：

- task 设模式（review / change / answer / monitor）+ 边界限制（files / deps / hash / agents）
- 在 PreToolUse 等 Hook 点跑 `decide()` 判越界，越界即拒

其拒令与 AIMH 铁律**逐条同源**：

| 拒令 | 对应 AIMH 铁律 |
|---|---|
| `HASH_NOT_AUTHORIZED` | 禁自作主张加保护/排序层 |
| `PATH_OUTSIDE_CONTRACT` | 删改用户文件须确认 |
| `DEPENDENCY_NOT_AUTHORIZED` | 零依赖原则 |
| `UNAPPROVED_SCOPE_EXPANSION` | 别擅自范围膨胀 |

**当前决策：不装。** 它仅支持 Claude Code / Codex / OpenCode / Hermes 的 host hook，WorkBuddy 不在列表；托管桌面端不能随便装第三方 hook，强塞会静默失效或误拦正常 AIMH 工作卡死。等 **WorkBuddy 自有 Hook 机制**支持 PreToolUse 拦截后，再评估移植其干净 decision 逻辑。
