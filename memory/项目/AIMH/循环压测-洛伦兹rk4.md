# 记忆循环压测：洛伦兹系统 RK4 两段式续算

## 实验设定

- 系统：洛伦兹吸引子 dx/dt=σ(y-x)，dy/dt=x(ρ-z)-y，dz/dt=xy-βz；参数 σ=10、ρ=28、β=8/3。
- 方法：经典 RK4 定步长积分，dt=0.01，起点 (x,y,z)=(1,1,1)。
- A 路（黄金答案）：从起点不中断连续积分 1000 步（t=10.00），结果落临时文件、不进 AI 上下文。
- B 路（被测）：第 500 步后模拟「上下文丢失」——末状态全精度写入本包，续算脚本不携带任何前文，仅经 AIMH 引擎查询本包、读取「断点状态」章取回状态，再积 500 步。
- 判定：B 路第 1000 步末状态与 A 路逐位（bitwise）一致 = 记忆取回零损耗、循环续算成立。

## 断点状态（第500步）

第 500 步末（t=5.00）相空间点，repr 全精度（17 位有效、float 往返无损）：

- x = -6.5120111040656745
- y = -6.97382971494569
- z = 23.92418085386587

本节是「遗忘模拟」的唯一真相源：第二段续算脚本不携带任何前文计算上下文，只经引擎查询本包并读取本节取回状态。

## 续算与对照（第1000步）

第二段脚本流程实测：L1 `query("洛伦兹 循环压测 断点状态")` 唯一命中本包（score 396.0）→ L3 `read_section` 取回「断点状态」章 → 正则解析出三元组 → 从第 501 步续算 RK4 至第 1000 步。

| 项 | 值 |
|---|---|
| B 路 续算末状态（第1000步） | (-4.902819483748822, -3.7434076752715657, 24.691885987964348) |
| A 路 黄金答案（第1000步） | (-4.902819483748822, -3.7434076752715657, 24.691885987964348) |
| **bitwise 一致** | **True** |
| **最大绝对差** | **0.0** |

判定：**记忆写回→引擎查询→取回解析→续算，全链路 float 无损**。agent 循环步骤可以把 AIMH 当工作记忆用，断点续算与不中断计算完全等价（RK4 确定性 + repr 17 位往返是零损耗的两个前提）。
