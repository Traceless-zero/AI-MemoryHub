# mdnote 开发日志

> 结构化、按时间顺序的工程记录：决策、改动、踩坑经过。

## 2026-07-27 选型：SQLite 而非纯 JSON
初版用 JSON 数组存索引，检索需全量载入内存。笔记目录上 G 后明显变慢。
改为 SQLite（`store.py` 封装），检索走 `LIKE` + 索引，内存占用恒定。
结论：索引类需求 SQLite 优于 JSON 文本。

## 2026-07-27 决策：检索只回路径 + 命中行
用户原想直接返回整段正文。但笔记正文可能很长，整段返回噪声大。
约定检索只回「路径 + 命中行号 + 该行文本」，需要深读再由调用方 `read_section`。
（此决策同步进 `约定.md` 的"输出铁律"。）
