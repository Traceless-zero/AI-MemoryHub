# mdnote 架构

> 其余按需文件示例：每个 md 单一职责。这里只讲检索管线与存储选型。

## 检索管线
`scan`（收集路径）→ `index`（建 SQLite 索引）→ `search`（LIKE 检索）→ 输出「路径+行」。
管线各阶段解耦，可单独重跑（如只 `index` 不 `scan`）。

## 存储选型
- 权威源：`notes/*.md`（用户笔记，永不进仓库）。
- 索引：`index.db`（SQLite，派生缓存，可重建）。
- 不引入向量库：关键词 `LIKE` 已满足本地笔记场景，避免过度设计。
