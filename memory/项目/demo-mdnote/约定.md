# mdnote 约定与铁律

> 把"死东西"（编码铁律、不可违反的规则）单独成文件，与结构、日志解耦。

## 编码铁律
- `index.db` 永远是派生缓存：任何写入索引的逻辑都必须能从 `notes/` 重建，不得把真相只存 db。
- `engine.py` 不碰 argparse；CLI 参数解析只在 `cli.py`。
- 检索函数纯确定性：不接受"相关性阈值"等模糊参数，命中即返回。

## 输出铁律
- 检索结果只返回「路径 + 命中行号 + 该行文本」，不返回整段正文。
- 需要深读时由调用方显式 `read_section`，不在检索层做正文拼接。

## 协作约定
- 新功能先写进 `需求清单.md` 的「未完成」，做完移「已完成」，再补 `开发日志.md` 一条。
