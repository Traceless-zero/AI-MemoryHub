# mdnote 需求清单

> 仿 README 式功能拆包：本文件只管"要做什么"，状态显式标 `已完成` / `未完成`。

## 已完成
- 全盘扫描指定目录，递归收集 `*.md` 路径清单
- 基于文件名 + 一级标题（`#`）建轻量索引
- 命令行按关键词模糊检索，返回路径 + 命中行
- 索引持久化到本地 `index.db`（SQLite）

## 未完成
- 增量索引：监听文件变更，避免每次全量重扫
- 正文级检索：命中后 `read_section` 取段落而非仅路径
- 标签检索：支持 `tags:` 过滤
- 跨笔记本多根目录配置
- `export` 子命令：把检索结果导出成 markdown 列表（2026-07-27 路由测试增补）
