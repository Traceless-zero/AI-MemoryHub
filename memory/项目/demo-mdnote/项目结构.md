# mdnote 项目结构

> 只描述目录与文件布局。铁律 / 约定请看 `约定.md`，本文件严禁塞死东西。

## 目录布局
- `mdnote/`：包根
  - `cli.py`：命令行入口（`scan` / `index` / `search` 子命令）
  - `engine.py`：索引构建与检索核心
  - `store.py`：SQLite 读写封装
  - `index.db`：运行时索引（可由 `cli.py index` 重建，非权威源）
- `notes/`：被检索的示例笔记目录（用户数据，不入仓库）

## 关键文件
- `engine.py` 是唯一含检索逻辑的文件；`cli.py` 只做参数解析与输出格式化。
- `index.db` 是派生缓存：删除后跑一次 `index` 即可恢复，不进版本库。
