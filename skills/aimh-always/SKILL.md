# HMA 记忆模式（WorkBuddy 常驻入口 · 骨架）

> **权威**：路由表 `references/router.md`（单一来源，勿另立速览）；路径与 MCP 部署 `工具与技能总览.md` §2.4（T31 钉）；隐私 C 类 `工程红线与自检纪律.md` §4；操作细则 `召回消歧管线设计（实现）.md` §14。
> WorkBuddy 不自动加载技能：用户 `@skill:aimh-always` 调出后常驻。

## 路径定位（首次 / 失效时跑，禁止推理猜路径）

`~/.hma_home` → `where.py --json` 登记 → 都不可得问用户。MCP 连接器：`deploy_mcp.py`（幂等）。细节召回键 `["路径定位"]`（工具总览 §2.4）

## 常驻准则（每回合默认带记忆意识，无需口令）

- **A 主动存**：持久事实 / 决策结论 / 方法论踩坑 / 非显然结论 / 用户显式说"记一下"。
- **B 主动取**：问题依赖过往上下文 / 连贯决策前 / 问可能已落库的角色项目细节。
- **C 不碰**：纯闲聊 / 一次性计算 / 临时草稿；**隐私 C 类**（名单见工程红线 §4）绝不外泄误写；上下文已充足不外查。

## 路由

意图判定 → 读 `references/router.md`（**全世界只有一份**，本文件刻意不复制——历史教训：三处各存一份导致单一真相源名存实亡）。非记忆类闲聊正常回应。

## 收录与查询执行

- 收录/项目/移包/归档/导入 → 按意图走对应流程：通用收录 `aimh-ingest`；OC 存取 `oc-dossier`；记账 `aimh-daylog-archive`；移包/归档/导入/诊断/路径部署 → intake 召回键（T24-T31）。
- 读取 → `aimh-recall`（含长尾细节模式）。
- **收尾纪律**：任何落库写 .md 后统一 `rebuild_index.py`（无头环境 `HMA_NO_GUI=1`）——索引永远只有一个真相来源。

## 显式启动与降级

- 用户说「启动 HMA 架构」等 → 回一句确认：已开启记忆模式（收录 / OC 存取 / 唤醒 / 客户端记忆迁移 / 项目工程收录），说「记一下」就收录、「回忆 X」就检索。
- 首次触达用户主动抛一句操作手册引导（手册包：`项目/AIMH-design-journal/用户操作手册.md`；用户说「用户操作手册」→ L1 定位 → L2 找节 → L3 取正文，口语化带练）。
- 「这次别记/关掉记忆」→ 停止主动路由，已落库保留；未配置 LLM key → ingest 退化为单包启发式。
