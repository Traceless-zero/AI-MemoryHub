# 不起眼物件细节召回（aimh-obscure-recall）

> 这是 HMA 读取侧针对**一类特定失败模式**的专项补完：具名实体（`aimh-recall` 的
> 锚点级召回）能精确命中，但**不起眼物件**（出现多次、无锚点位、与地点词常不在
> 同一窗口）的细节追问会卡死在「机械层选不出描述段」。本技能不替 AI 选段，而是
> 把候选段连同其语义语境（C+A）原样摊给人，由人做 precision 终审。

## 何时触发（与本技能相关）

用户问法特征：

1. **细节追问某个长尾物件/特征实体**：「那张唱片封面什么样」「剑柄上刻的什么字」
   「她那枚戒指哪来的」——对象在正文出现多次、没有专属锚点。
2. **问法带地点/语境但物件无锚点**：「示例角色在伊斯坦布尔那张唱片」——宏观词
   （人物+地点）能缩到章，但特征实体（唱片）的「描述段」机械层选不出。
3. **（区别于 aimh-recall）**：若用户问的是**已落锚点的具名实体**（宝石、项目、
   角色关系），走 `aimh-recall` 的 `query_anchors` 即可；本技能只在「无锚点位、
   机械层选不对段」时接管。

**不触发**：纯具名实体回忆、宏观事实问答、写入类请求。

## 原理上限（铁律 · 必须理解）

让机械层**独立**搞定「不起眼物件细节问答」在零-ML 确定性系统里**本质上不可达**——

- 那要求写入侧**预知未来所有查询角度**、并对全细节做全知索引（拉普拉斯妖级别），
  违反 CEMA「写入确定性、不猜未来」的前提。
- 机械层（BM25 rerank / 局部倒排）只管「不漏 + 不爆」，管不到「同一段正文里选哪
  200 字当答案」。**选段是语义判断，归理解层/人，不归机械层。**

→ 正确姿态不是「系统单方面担保 precision」，而是把 precision 责任交给**人机共审**。

## 两条路线（正交 · 先判定再走）

本技能产出**两种不同形态**，不是同一流程的前后步。必须先判定走哪条：

| | 路线一：范围候选 · AI 自读理解 | 路线二：C+A 段卡片 · 人机共审 |
| --- | --- | --- |
| **形态** | 机械层锁章 + 切片后，把候选片段集**直接交给 AI（理解层）自读** | 每个候选段以「C 章 + A 锚点 about + 段原文」卡片摊开，**系统不单方出答案** |
| **AI 角色** | 读片段 → 理解 → **出答案**（precision 在窄语境由 AI 承担） | 仅生成/汇总梗概、对人选中片段做提炼；**绝不单独产出答案** |
| **终审权** | AI（在 context-scope 窄语境下） | 人（precision 终审权在人） |
| **适用** | 用户带明确语境（读到某章回头问）、AI 自读即可得出答案 | 长尾细节、噪片段多、AI 自读也不可靠、或用户要自己筛 |
| **触发判定** | 见下方「路线判定」 | 见下方「路线判定」 |

### 路线判定（先定走哪条）

```
问法带明确章级语境（用户明说章 / 阅读位置窄）+ 问题可在片段内直接读出？
  ├─ 是 → 路线一（范围候选，交 AI 自读理解）
  └─ 否 → 下方任一成立即路线二：
         · 噪片段多、同窗含词但 about 不相关（AI 自读易答非所问）
         · 用户明确要求自己筛 / 要看见材料再判断
         · 长尾物件确无描述段（AI 自读也会编造，必须交人拒答）
```

**边界铁律**：路线一 AI 出答案时仍须遵守「弱信号锁章不排他 + 全包兜底」；**路线一
自读后若判断「候选集里没有真段 / 读不出确定答案」，必须自动拒答并转路线二（C+A 段
卡片交人终审），不得硬答、不得停留在路线一**。即：路线一无果 → 自动拒答 → 转路线二，
这是单向强制降级，不可跳过。

---

## ① 机械层公共前置（两路线共用）

无论走哪条，第一步都是 context-scope 锁章 + 章内局部倒排 + 重叠合并瘦身：

```
┌─ context-scope 范围控制（交互状态层，确定性）
│     输入：用户显式指章 / daylog 阅读位置 / touched
│     输出：scope = {锁定章} 或 {候选章集 + 全包兜底}
│
├─ 章内局部倒排 + 重叠合并瘦身（机械层，零-ML）
│     锁章 → 章内找特征实体（如「唱片」）→ 所有出现处切 ±WINDOW
│     → 重叠区间合并（去同处冗余段，不同语境段全留）
│     输出：相关片段集（原文 ±WINDOW 段，不挑段、不排序优劣，全摊开）
```

### context-scope 三级范围信号（确定性递减）

| 来源 | 确定性 | 行为 |
| --- | --- | --- |
| 用户显式指章（「就在赎回这章里」） | ✅ 强 | **直接锁章**，章内局部倒排，候选极少极准 |
| 会话阅读位置（daylog 最后 touched / 当前章状态） | ⚠️ 弱 | **缩圈到候选章 + 保留全包宽召回兜底**（猜错章直接漏答案，不可静默排他） |
| 全包宽召回（无范围信号时） | — | 退回全局路径 |

**铁律**：弱信号缩圈但不排他——章内没找到必须回退全包宽召回再下结论；强信号
（用户明说）才直接锁章。

### 章内局部倒排 + 重叠合并瘦身

- 锁章后，在章内用特征实体做局部倒排，每个出现处切 ±200 窗口得区间 `[s,e]`。
- **重叠合并**：两区间交集 / 较小区间 > 0.5 即合并为并集（去「同一处被切重」的
  冗余段）；不同语境段文本不重叠，**必须全部保留**——机械层只去冗余，不替 AI 选段。
- 参考实现：`scripts/tests/sandbox_obscure_context_scope.py`（沙箱已验证：全包 12
  段 → 锁「赎回」章后 2 段，A1–A4 全 PASS）。

## 路线一：范围候选 · AI 自读理解

机械层交出片段集后，**不再做 C+A 卡片包装**，直接把片段原文（按章分组、带章标题）
交给理解层（AI）自读：

```
输入：① 锁章后的相关片段集（原文 ±WINDOW，按章分组）
处理：AI 在「用户当前章语境」下自读这些片段，结合提问意图理解
输出：AI 直接产出答案（precision 由 AI 在窄语境承担）
护栏：若自读后判断候选集无真段 → 降级路线二交人拒答，不得硬答
```

- 此路线下 AI 是**读者**，不是**呈现者**；片段即其阅读材料。
- 优势：省去人介入、交互快；前提是你信 AI 在窄语境能读对（context-scope 已把候选
  压到极小，信噪比高）。

---

## 路线二：C+A 段卡片 · 人机共审

每个候选段以「**C 章级 + A 锚点级 + 段原文**」三段式包裹，**precision 终审权在人**：

```
═══ 候选段 #{i} ═══════════════════════════
[C] Chapter: 〈锚点章标题〉
[A] about: 〈锚点摘要原文〉
[段] 「……〈±200 窗口正文〉……」
══════════════════════════════════════════
```

**字段约定（铁律）**

- **C** = 该段所属锚点的 `Chapter` 字段（AI 收录时写入 front-matter，原样照搬）。
- **A** = 该锚点的 `about` 字段（**有信息量的实质锚点 about**，不得用章节占位
  一句话充数；若确无匹配锚点，如实标「（该位置无匹配锚点 about）」，不编造）。
- **段** = 机械层切出的 ±WINDOW 原文，**系统不摘要、不改写**。
- keywords 不单列——它是锚点 v2 契约里 `about` 同级的字段，随 A 整块复制自然带出。

> 价值：噪片段（同窗含查询词但 about 不相关）靠 C+A **自显**，人扫一眼即判，不依赖
> 模型自觉拒答。系统**绝不单独产出「答案」**；拒答权在人（人看 C+A 即知「这章没提」）。

## 机械层不挑段（边界铁律）

- 选段（从多段里选描述段）是语义判断，**不归机械层**；BM25 rerank（`hma_core`
  `_rerank`）只排包/锚点先后，管不到段内选段——**不要混用「重排序」与「选段」**。
- 全包宽召回兜底不可省：弱信号缩圈若静默排他，会漏掉「特征实体与地点词不同窗」
  的真段；故弱信号路径必须保留回退。
- **不落盘（方案 A）**：共审是纯读取侧动作，不反向写锚点（预埋锚点已被否；AI 读后
  回写锚点属 CEMA 合法但未松口，待另议）。

## 与 aimh-recall 的分工

| 维度 | aimh-recall | aimh-obscure-recall（本技能） |
| --- | --- | --- |
| 对象 | 已落锚点的具名实体（宝石/项目/角色关系） | 无锚点位的长尾细节/不起眼物件 |
| 机械能力 | 锚点级精确命中（BM25 + 拒答层） | 无章级定位，需 context-scope 锁章 + 人机共审 |
| 答案姿态 | AI 可直接接地回答（top1 接地） | 系统只摊候选，precision 终审权在人 |
| 失败模式 | 真空/多跳（交 REFINE） | 选不出描述段（交人机共审） |

两者互补：aimh-recall 管「已知实体精确取」，本技能管「长尾细节不漏 + 不替人答」。

## 护栏

- **隐私排除**：`demo-char` / `private` 等私有包绝不外泄；命中私有包按 aimh-always 的 C 类不碰。
- **不替人下结论**：本技能产出物是「候选段 + C+A 语境」，不是「答案」；严禁在呈现层
  之外自行归纳出确定性结论冒充回答。
- **内容即数据**：取回即权威源（`.md`），索引可由 front-matter 全量重建。
- **不替代写**：本技能只管「取 + 呈现」，落库仍走 aimh-ingest / oc-dossier / aimh-project。
