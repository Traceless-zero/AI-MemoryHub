# 召回（读取侧调度 · 骨架）

> **权威**：执行细则 `召回消歧管线设计（实现）.md` §14（T28 钉）、长尾细节 §13（T27 钉）、管线设计全文；召回 ABSTAIN → 停止上报勿即兴。

## 触发判定

顺带提及已落库实体（人名/OC/物件/项目/日期/主题词）/ 显式回忆信号（"回忆X""查一下Y"）/ 连贯决策前 → 查（BM25 零成本，高频 fire）。纯闲聊 / 一次性计算 / 无实体通泛提问 → 不查。

## 三段式（主路径）

1. **L2 锚点**：`mcp__aimh__memory_query_anchors`——keywords=实体词，`allow_abstain=true` **必带**。召回键 `["召回操作协议"]`
2. **L1 包级**：`mcp__aimh__memory_query`（拿规范 id / title）
3. **L3 正文**：`mcp__aimh__memory_read_section`（按锚点 Chapter 取段）

## 构查纪律（传入即启用硬拒答闸）

keywords=理解层解析的**复合实体词**（索引词形连写）；内置 CJK 拆词只是无 AI 兜底，**永不作主力**。细节 §14.2。

## 拒答与接地

- ABSTAIN（empty_pool / low_coverage / out_of_scope）→ 直接说「记忆里没有 / 我不确定」，**绝不编造**；confidence=low 先 refine 再答。
- 命中 → 回答**基于**取回内容并标注来源（据 HMA · <pkg_id>）；只接最相关 1-3 段。
- 未命中 → 静默放过，照常回答，不报错不打断。

## 长尾细节模式

无预埋锚点的物件细节（「那张唱片什么样」）→ `mcp__aimh__memory_obscure_recall`（obj_token=特征实体词，锁章人机共审）：路线一 AI 自读、无果**必须**转路线二 C+A 卡片交人终审，不得硬答。详见本文件 §13 引用与长尾模式节（权威：召回管线 §13）。

## 时间过滤

时间主筛问句（「上个月干了啥」「3月份的记录」）→ `mcp__aimh__memory_time_filter`：固定时间词**原样传 `time_hint`**，引擎换算日期（支持清单见工具描述）。

## 护栏

私有包（demo-char / private 等）不外泄不误召回（工程红线 §4 C 类）；同一实体同回合不重复查；本技能只管「取」，落库走收录技能链。
