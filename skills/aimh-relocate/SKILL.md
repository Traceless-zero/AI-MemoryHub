# HMA Relocate（归类纠错 / 移包，确定性）

## Overview
收录钩子（`aimh-ingest` 第 6 步）给了用户两个关键字：**「移包 <目标>」** 和 **「合并 <已有包>」**。
本技能就是这两个关键字的执行体——把用户的纠错意图翻译成**一条确定性命令**，
调用 `scripts/core/relocate_package.py`，**绝不做任何 LLM 推断的落库**。

> 设计哲学：理解归 AI（判定"该不该改、改成哪"），但**实际搬家纯确定性**。
> 本技能只解析"源 / 目标"并调用脚本，不重写 `.md` 正文、不重新拆包、不调 LLM 落库。

## 第 0 步：解析意图（你来做理解）
从用户回复里抽出：
- **操作类型**：`移包`（relocate，改路径 / 改名）还是 `合并`（merge，并入已存在包）。
- **源包（src）**：用户刚收录的那个包。若用户没明说，默认取上一次收录钩子报告的 `<package_id>`（回看对话即可）；拿不准就问。
- **目标（dst）**：
  - 移包 → 用户给的新路径（如 `其他/哲学/尼采`）；若用户只说"移到尼采"，用 `query` 找最匹配的现有包路径。
  - 合并 → 用户给的**已存在包**名（如 `尼采`）；用 `query` 解析成完整 `package_id`。

## 第 1 步：执行（确定性，二选一）
在 `hma/` 目录下：

**A. 移包（整包搬迁到新路径，新路径须不存在）**
```bash
python scripts/core/relocate_package.py <memory_root> "<src包路径>" "<dst包路径>"
```
脚本：搬整目录 + 删旧索引及子孙 + 新位置逐包重挂；**拒绝覆盖已存在目标**（防误并包）。

**B. 合并（src 整体并入已存在的 dst 包）**
```bash
python scripts/core/relocate_package.py <memory_root> "<src包路径>" "<dst包路径>" --merge
```
脚本：把 src 下所有事件 `.md` 移进 dst 目录 + 删 src 索引 + 重挂 dst + 清理 src 空目录。
（合并前提是 dst **已存在**；若 dst 不存在则退化为"移包"，请改用 A。）

## 第 2 步：回报 + 核对
- 把脚本输出的搬迁 / 合并清单原样回报给用户。
- 顺手核对：`query <root> "<关键词>"` 确认 dst 包现含合并后的全部事件、`linked` 跨包引用仍按 id 生效。
- 若用户还想继续微调，提醒"再回复「移包 / 合并」即可"。

## 纪律（铁律，不得违反）
- **只搬家、不重造**：本技能绝不重写 `.md` 正文、不重新拆包、不调 LLM 落库。
- **确定性优先**：所有写操作走 `relocate_package.py`，索引可重建，`linked` 按 id 关联不受路径影响。
- **防误并包**：移包拒绝覆盖已存在目标；合并要求 dst 已存在，避免把不相关的并掉。
