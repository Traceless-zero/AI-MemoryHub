  - 触发条件：AI 正要读/已读入一篇**超长文本（书籍 / 长篇资料，字数达几万级）**（默认阈值见下「触发与回问」），

# 世界书拆解器（骨架）

> **权威全文**：`memory/项目/AIMH-design-journal/拆包与收录规范.md` §7.1（拆解产物 schema / 聚合包铁律 / 执行流程）；§7 正文（单包上限与鸿篇巨制拆分）。
> **执行规则**：按召回键查询；**ABSTAIN → 停止并报告，勿即兴**。

1. **触发与回问**：几万级长文且整篇入上下文不经济 → 回问用户（**绝不静默拆解**，落多包改记忆结构须显式确认）；拒绝则退回普通读取/ingest 短包路径。召回键 `["世界书"]`
2. **拆解产物**：概览包（全字段填实）+ 分章包（正文大段散文+本章实体）+ 人物/概念聚合包（**索引视图不抄内容**，linked 指分章）；聚合包只对跨多章核心实体建。
3. **边界铁律**：**单人视角作品整体不适用**（退化为 character diary）——保持单包全字段，token 过大靠读取侧按需取 anchors 片段。
4. **执行（CEMA）**：AI 抽实体 → 规划包结构 → 直写 .md（SCHEMA §2.8 范本，**勿走 hma.cli write**——丢四要素与 pkage_*）→ rebuild → lint 验收。
