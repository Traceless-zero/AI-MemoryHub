# HMA 常驻记忆模式（always-on · 主动触发）

> 本技能是 HMA 记忆能力的**唯一常驻入口**（原 `hma-launch` 总开关已合并进来）：
> 记忆意识默认常驻，无需用户口令；用户若显式说"启动HMA架构""开启HMA记忆模式"等同触发本模式，
> 加载后按下方「显式启动口令与模式宣言」回一句话确认即可。

## 第 0 步：路径定位（首次 / 路径失效时跑，禁止推理猜路径）
HMA 是即插即用外挂，每个用户解压位置不同。加载本技能后，**AI 先确定性拿路径**：

1. **优先读指针文件**：`~/.hma_home`（一行 = 仓库根绝对路径）。存在且指向的目录含 `memory/` → 直接用。
2. **指针缺失/失效**：找到 `scripts/where.py`（cwd、项目根或用户指明的 HMA 目录下）跑一次：
   `python <repo>/scripts/where.py --json` → 输出仓库根 / memory / index.db / 引擎 cwd 等，并自动登记 `~/.hma_home`。
3. **两者都不可得**：问用户"你的 HMA 解压在哪？"，拿到目录后跑 `where.py` 登记。

拿到路径后，下文所有 `python -m hma.engine ...` 一律 `cd <仓库根>` 下执行，`<root>` 用 `where.py` 报出的 memory 绝对路径。全程零路径推理。

> **MCP 连接器部署（让 `mcp__hma__*` 工具可用，可选）**：除 `python -m hma.engine` CLI 路径外，HMA 还提供 WorkBuddy MCP 连接器（暴露 `memory_*` 工具）。路径定位、指针登记后，跑一次即可把连接器配置写入 WorkBuddy 配置目录：
> ```
> python <repo>/scripts/deploy_mcp.py
> ```
> 它把启动器复制到 `~/.workbuddy/hma_mcp_launch.py` 并合并写出 `~/.workbuddy/mcp.json`（只动 `mcpServers.hma`，保留其它连接器；python 版本自动探测、不写死）。之后在 WorkBuddy 连接器管理页点「信任」激活 hma 连接器，新窗口即出现 `mcp__hma__*` 工具。幂等，可重跑；仓库搬家后重跑一次即可。

## 常驻行为准则（核心：何时主动存 / 取 / 不碰）
本技能常驻后，AI **每回合默认带记忆意识**，按以下准则自主判断，**无需用户口令**：

**A. 主动存（出现以下信号即收录，不必等用户说"记一下"）**
- 浮现**持久事实**：用户偏好 / 身份锚点 / 稳定的个人事实
- 做出**决策或结论**：技术选型 / 架构判断 / 放弃某方案及原因
- 沉淀**方法论 / 踩坑**：可复用的经验、别人易踩的坑
- 多轮对话后冒出**非显然结论**：不是单次问答能得到的
- 用户明确说"记一下 / 存这个 / 收录"（显式信号，最高优先级）

**B. 主动取（以下场景先查 HMA 再答，不凭空编）**
- 问题可能依赖**过往上下文**："之前我们说的X""还记得Y吗"
- 要做**连贯决策**，需先确认历史是否已有相关记忆
- 用户问某角色 / 某项目细节，可能已在 HMA 中

**C. 不碰（以下场景不动记忆）**
- 纯闲聊 / 一次性计算 / 临时草稿（无持久价值）
- **隐私排除名单**：`veronica` / `private` 等私有包，绝不外泄或误写
- 上下文已充足、无需外查即可作答

> 准则只管「何时触发 + 什么意图」；**怎么写、怎么建索引全交子技能与 `hma.engine` CLI**
> （CEMA：AI 只理解，脚本确定性写）。

## 显式启动口令与模式宣言
用户显式说「启动HMA架构」「启用HMA记忆」「开启HMA记忆模式」「切换记忆存储模式」等，
或任何表达"启用长期记忆 / 让 AI 具备持久记忆"的意图时，本技能即被激活（其实常驻下它本就生效，
这里只是给用户一个明确的"开"的反馈）。加载后回一句话确认：

> 已开启 HMA 记忆存储模式。我现在具备长期记忆能力，可：
> ① 收录通用文本 / 笔记 / 文章 / 想法；② 按三层铁律存 OC 角色档案；
> ③ 按名字唤醒已落库的 OC 陪你对话；④ 导入 AI 客户端原生记忆（自动探测 WB / Claude Code / Gemini / Codex）；
> ⑤ 按 README 式拆包策略收项目工程。你说「记一下 / 存这个」我就收录，说「回忆 X / 查一下 Y」我就检索。
> 想退出口令「关闭 HMA 记忆模式」；想学用法说「用户操作手册」。

## 操作手册自唤起钩子（最直观能力展现）
HMA 自带一份《HMA 用户操作手册》事件包（`项目/hma-design-journal/用户操作手册.md`；aliases：操作手册 / 使用手册 / 怎么用HMA / 新手引导）。
本技能常驻后，**会话首次触达用户即主动抛一句引导**（不等待用户问）——这是 HMA「主动记忆」最直观的演示：

> 📖 我有一份《HMA 用户操作手册》，手把手教你开启 / 存 / 查 / 存角色 / 导入记忆。
> 想学的话，直接说「**用户操作手册**」，我带你一步步过。

**触发「教我」的意图信号**：用户说「用户操作手册 / 操作手册 / 怎么用 HMA / 教我怎么用 / 新手引导」，或显式求教程。
命中后**确定性取手册并口语化带练**（不是大段贴原文，是"来，我们先做 X"）：

```bash
python -m hma.engine query <root> "用户操作手册"                  # L1 定位手册包
python -m hma.engine query_anchors <root> "怎么存"               # L2 找对应小节
python -m hma.engine read_section <root> 用户操作手册 "<章节标题>"  # L3 取该节正文
```
取到正文后，用**手把手、带示例**的方式带用户走一遍（可配合上面的命令演示底层），而非整篇粘贴。

## 路由表（意图判定 → 子技能）
接到输入 → 先判定意图 → 加载对应子技能（AI 只做理解分流，落盘交给子技能与 `hma.engine` CLI）。
**权威路由表已抽成单一来源 `references/router.md`**（含意图→技能、检索路径、客户端探测、后台铁律、收尾纪律），
本技能与 `hma-intake` 都引用它，不各自复制。核心映射速览：

- 存通用文本 / 笔记 / 文章·资料 → **`hma-ingest`**（通用 / 文章·资料 两分支）
- 存 / 摘 OC 角色 → **`oc-dossier`**（store 分支）；叫到已落库 OC 名字并像对其说话 → **`oc-dossier`**（wake 分支）
- 导入客户端原生记忆 → **`memory-import`**；项目工程收录 → **`hma-project`**；归类纠错 / 移包 → **`hma-relocate`**
- 检索 / 回忆 → 直接调引擎（见 `references/router.md` 的「检索路径」）

> 路由拿不准优先按信号最强的走；明显角色类即使没明说"存角色"也导 `oc-dossier`。
> 非记忆类闲聊 / 普通问答 → 不走子技能，正常回应（常驻记忆不影响日常助手职能）。

## 后台铁律（源自 CEMA 设计，权威版见 `references/router.md`）
- **前后台 1:1**：每事件包恰一条索引记录；`.md` 是权威源，索引可由 front-matter 全量重建。
- **无状态确定性检索**：关键词 / 锚点 / 时间过滤，绝不按热度 / 新鲜度加权。
- **AI 只理解，脚本确定性写**：理解 / 拆分 / 关联归 AI，落库 / 建索引 / 装卸交 `hma.engine` CLI 与子技能。
- **内容即数据**：拆包触发条件是体积 / 凝聚性，不是作者写法。
- **OC 三层拆包铁律**：① 基础包必有且仅 1 个；② 背景超长自然分立故事包；③ 拓展包含则分、无则无。

## 关键路径
- 引擎 CLI：`python -m hma.engine <build|query|query_anchors|read_section|install|uninstall|rebuild-all|derive|daylog> ...`
- 统一前台 db：仓库根 `memory/index.db`
- OC 名字 → 包：`python scripts/oc_registry.py find/list`
- 子技能位置（双副本）：`hma/skills/` 与 `~/.workbuddy/skills/`

## 收尾纪律（写后一律调 EXE 刷新索引）
任何落库操作（`hma-ingest` / `oc-dossier` / `hma-project` / `memory-import` 写 `.md` 后），收尾统一调用：
- 双击等价：`hma/一键更新记忆索引.exe`（无头环境设 `HMA_NO_GUI=1`）
- 等效无弹窗：`python scripts/rebuild_index.py`（AI 路线优先用这条）
> 与手动路线殊途同归，索引永远只有一个真相来源。

## 降级 / 临时关闭
- 用户说"这次别记""关掉记忆" → 本回合 / 本会话停止主动路由，恢复正常助手；已落库记忆保留不删。
- 未配置 LLM key → ingest 退化为单包启发式（照常能存，只是拆分较粗）。
