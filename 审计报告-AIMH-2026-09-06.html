三、问题清单（按优先级）

P1 高A. 测试体系名存实亡，与「全绿」宣称背离（最核心）
证据：21 脚本实跑 10 干净退出、2 语法错误、7 失败/崩溃；5 个硬编码旧绝对路径；tests/ 整个被 .gitignore 不入库；无统一 runner（real_regress.py 自身也硬编码死路径）；README 写「14 项正式回归锁定（全绿，可一键复跑）」。
机理：9/5–9/6 密集重构（废除 corpus_hit_rerank、veronica→demo-char 改名、锚点调整）后未同步维护仪器；而测试不入库 + 无 CI + 无 compileall 门禁，使破损静默累积。颇具反差的是，《工程红线与自检纪律》把「改完跑全量回归、声称通过必须给数字、不得洗绿」列为铁律，但缺让铁律自动生效的机制。
建议：① 先修 2 个语法错误（把 demo-char 改回合法标识符 / 对齐真实模块名）；② 全部脚本用 __file__ 推导仓库根，消灭硬编码绝对路径；③ 写一个 run_all_regress.py 统一 runner，输出「通过/失败/红基线」三态汇总与非零退出码（契合项目「确定性脚本」哲学）；④ 明确测试入库策略：要么补脱敏合成 fixture 让外部可复跑，要么 README 如实改口径为「本地私有仪器，不对外承诺」。
P2 中B. hma_core.py 4552 行上帝模块
603 个 if、338 个 for；最大方法 query_anchors 155 行、resolve_query 145 行；机械层 / 手写 YAML 解析器 / EventPackage / 2450 行 Memory 大类 / 聚合时间函数全挤在一个文件。
建议：沿已有外拆趋势（recall_obscure / routing / refine / time_iso / engine.handlers）继续抽：FM/YAML 解析、retrieval、aggregate+time、write 各成模块。手写 YAML 子集解析器只支持缩进项，迁移外部记忆遇流式 {} / 多行串 / 引号转义会静默丢字段——而它本应有的护栏测试 regress_fm_schema_kw 恰好语法错误，建议优先补解析器单测。
P2 中C. 文档/注释自相矛盾（墓碑漂移）
①《工具与技能总览》同文件三处技能数：summary「8」、§四标题「12」、锚点 about「13」，表格仍描述 4 个已退役技能；② scoring_coeffs.py L55-56 注释仍写 *0.6，tag 实际已 0.6→0.8；③ 技术参考 §7.6 称 coverage_gate 10/10，实测 6/10；④ SCHEMA linked 指向已不存在的《…数学与语言哲学思路.md》；⑤ README 结构图仍写 AIMH/、managed python 记 3.13.12 实为 3.13.14。
建议：这些正是项目自定义的「墓碑注释/注释对账」对象，可用现成的 audit_comment_pins.py 思路扩一个「文档数字/清单一致性」静态检查，把对账从自觉变成脚本。
P2 中D. 防护不对称：读侧严、写侧松
网页控制台 /api/md 有目录穿越防护、aggregate 用只读 URI+列/算子白名单；但 MCP memory_write → Memory.write 的 id 直接 os.path.join(events_dir, id+'.md')，无归一/越界校验（new_package.py 反而有路径软检查）。id 含 ../ 或绝对路径可写出 memory 树。
建议：给 write() 补一道与读侧同等级的路径软检查（normpath 后必须仍在 repo 内），MCP 边界拒绝越界 id。单机自用时风险低，但 MCP 由 AI 客户端驱动，值得对齐。
P2 中E / F. 副本漂移与基准不可复现
E：sync_skills diff 实测 4/8 技能用户级≠项目级（aimh-recall 连 SKILL.md 都不同），与「改完 push 镜像」纪律不符。F：LoCoMo/MemoryStress 脚本归档工作区外、测试与私有语料不入库，README 的 hit@5 89.7–92% 外部无法复跑。
建议：E 跑一次 sync_skills.py push 收敛并把 diff 纳入一键自检；F 保留区间口径（已做得诚实）的同时，在 README 显著标注「基准为本地私有语料结果、脚本不在本仓」，避免外部读者误读为可复现基准。
P3 低G–K. 收尾与卫生项
  • G 在制工作未收尾：hma_core.py 有未提交改动（接入 time_iso），time_iso.py / parse_time_iso.py 未跟踪，time_iso 自测 35/36；建议补「3月份」裸月份分支到 36/36 后一次提交（AGENTS.md 要求工作区干净、验证后及时 commit）。
  • H 8MB 一键 exe 入库：二进制进 git 历史永久膨胀、不可 review、源码更新后不重打包即过期；建议改走 Release 附件分发。
  • I 3 处私有语料 linked 悬空边：conv-meeting-21、daylog-2026-09-03、待办事项指向不存在的包，multihop 沿边 BFS 时是断链。
  • J scripts/real_regress.py 硬编码旧绝对路径（两处），直接运行即失败。
  • K audit_orphans 小盲区：函数内 import … as 别名 识别不到，把已接线的 time_iso.parse_text 误报为孤儿（工具自身已诚实声明偏保守，补别名分析即可）。
